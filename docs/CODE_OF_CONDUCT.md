# Code of Conduct

ZipPack follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback, and
focus on what is best for the project and its users. Harassment, insults, personal attacks and publishing
other people's private information are not tolerated, in issues, pull requests, discussions or anywhere
else the project is represented.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately through the
repository's **Security → Report a vulnerability** form (it reaches only the maintainers), or by the
contact listed on the maintainers' GitHub profiles. All reports are handled confidentially.

Maintainers may remove comments, commits, issues and other contributions that break this code, and may
temporarily or permanently ban contributors for behaviour they deem harmful.

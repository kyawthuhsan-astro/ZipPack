- **7-Zip / unRAR restriction.** The RAR decoder in `7z.dll` may be used to extract RAR archives, but its
  code may not be used to develop a RAR (WinRAR) compatible archiver. Full text:
  https://www.7-zip.org/license.txt.
- **Icons.** The tool bar icons are drawn at run time from the *Segoe Fluent Icons* / *Segoe MDL2 Assets*
  fonts that ship with Windows; no font files are redistributed. The application icon is generated by
  `ZipPackNet/Assets/make-icon.ps1`.
- **Windows taskbar progress** uses the Windows Shell `ITaskbarList3` interface directly (the interface the
  Windows API Code Pack wraps); no Code Pack binaries are included.
